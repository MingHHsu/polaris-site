隱私權政策

最後更新：2026-11-08

Polaris 是個人使用的工具。本政策說明它如何處理資料。

我們存取的資料

  • Google 帳號授權：透過 OAuth 取得 drive.file 範圍的權杖，只能存取 Polaris 自己建立的檔案。
  • 收支與發票資料：由使用者自行提供（例如財政部電子發票載具匯出檔）。

資料如何使用

  • 資料只用來整理收支，並寫入使用者自己 Google 雲端硬碟中的試算表。
  • 授權權杖與資料儲存在使用者自己的電腦上，不會上傳到 Polaris 的任何伺服器（Polaris 沒有自己的伺服器）。

分享與販售

我們不會出售、出租或與任何第三方分享你的資料，也不用於廣告或訓練模型。

Google 使用者資料

Polaris 對 Google 使用者資料的使用與傳輸，遵守 Google API 服務使用者資料政策，包括其中的有限使用（Limited Use）規定。

保存與刪除

  • 你可以隨時刪除本機的資料目錄，以及雲端硬碟中由 Polaris 建立的試算表。
  • 你可以到 Google 帳戶的第三方存取權設定撤銷 Polaris 的授權。

聯絡方式

如有問題，請到 GitHub Issues 留言。

Privacy Policy (English)

Polaris is a personal tool. It requests only the drive.file Google scope, which limits access to files the app itself created. Tokens and data are stored on the user's own computer; Polaris operates no servers. We do not sell, rent or share your data with third parties, and do not use it for advertising or model training. Polaris's use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements. You can revoke access at any time at myaccount.google.com/permissions. Contact: GitHub Issues.
